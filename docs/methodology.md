# 阈值附近效果识别的方法与口径

本文件记录分析的识别策略、推断路径选择与纪律性约束。代码实现见
`threshold_data/`，每一条约束都有对应模块与测试。

## 1. 资格规则与数据口径

- 每个政策批次自带 `cutoff`、`eligible_above`（资格在阈值哪一侧）与
  `inclusive`（等号归属）。资格判断函数是 `policy.is_eligible`，有符号
  阈值距离在资格一侧恒为非负（`policy.signed_distance`）。
- `applications.score` 是公布前冻结的连续评分，**历史资格只由它计算**。
  `score_revisions` 是后补资料，只进入 `prep` 的修订审计；任何修订分都
  不覆盖冻结分。审计输出每条修订的 `known_day`、是否事后公布、是否会
  改变资格（`post_publication_flip`）。
- 企业多期出现时，主分析只保留**首次有效申请**（按批次登记顺序与申请
  id 确定确定性次序），其余时期进入辅助样本并在 `exclusions.json` 留痕。
- `outcome_known_day` 超过固定观察窗（默认 90 天）的申请不进主样本。

## 2. 先诊断、后解释

任何效果数字之前必须通过 `diagnostics` 的检查：

1. **评分堆积**：比较阈值两侧格点计数，用 Fisher 精确检验（大样本自动
   切换为固定种子的超几何 Monte Carlo）判断密度是否不连续；
2. **基线连续性**：把政策前 `baseline` 当结果跑同一局部模型，阈值处
   跳跃显著即报警；
3. **样本稀缺**：报告两侧计数、独立企业数、每格点平均样本；
4. **第一阶段**：领取率 `received` 对资格的跳跃与稳健 F 统计量；
5. **伪阈值**：把资格规则平移到不含真实阈值的位置，显著的伪跳跃说明
   观测到的跳跃未必来自资格规则；
6. **donut 敏感性**：两侧各删最近的 k 个格点，删除的格点距离逐一记录；
7. **窗口敏感性**：预先固定的窗口×权重×donut 全网格全部估计、全部写入
   `sensitivity.csv`，不存在“最优带宽”，禁止按显著性事后挑选。

诊断未报警只表示现有数据**未证伪**密度连续与基线连续。精确操纵不
存在、排除限制（exclusion restriction）与单调性（monotonicity）本身
不可由这些数据证明，报告不得声称它们已被证明。

## 3. 离散评分：不加噪声，换用有依据的推断

当阈值距离的不同取值数低于门槛（默认 10）或并列占比超过 20% 时，
`support.support_summary` 判定为离散支撑。此时：

- **绝不向评分加噪声或抖动**把数据伪装成连续；
- 转入 `randomization` 的 Fisher 随机化推断：在窄窗口内把资格视为近似
  随机分配，置换在批次内分层进行，保留批次结构；
- 组合数可行时枚举全部排列给出精确 p 值，否则用固定种子的 Monte Carlo
  近似（p 值带 `(1+hits)/(1+reps)` 修正）；
- 置信区间由加性常数效应下的检验反演得到；
- 窗口选择**只看政策前基线平衡**（取基线平衡的最窄窗口），全程不看
  outcome 与 received；没有任何窗口平衡时明确停止并说明原因；
- 离散小样本下模糊断点没有可靠的比值抽样理论，第一阶段不显著就停止
  报告 LATE，只保留 ITT 与领取率证据。

## 4. 连续支撑：局部加权回归

支撑足够连续时使用 `estimation` 的局部线性模型：

- 设计矩阵为截距、资格指示 E、中心化距离 d、E×d，再加批次固定效应与
  批次特定斜率；多批次保留结构，**不把异质强度拼成一条曲线**，并提供
  逐批次跳跃 `batch_specific_jumps`；
- 权重支持均匀核与三角核；三角核边界权重为 0 会让小窗口损失整侧观测，
  实现中加不改变核形状排序的小常数保证正权重；
- 标准误按 `firm` 聚类（Liang-Zeger 小样本修正）；聚类数足够时附加
  Rademacher / Webb wild cluster bootstrap-t，不沿用普通标准误；
- 极小窗口下降秩为水平跳跃模型；结果无变异（如全部未领取）时显式标记
  退化，不抛奇异矩阵错误。

## 5. 三个跳跃与弱一阶段闸门

每个窗口分别报告：

1. **ITT**：资格 E 对业务结果 `outcome` 的跳跃；
2. **第一阶段**：E 对实际领取 `received` 的跳跃；
3. **LATE**：假设成立时 ITT / 第一阶段的比值。

第一阶段 F < 10（弱）或跳跃方向反常时，`estimate_window` 将
`late_status` 标为 `weak_first_stage` / `wrong_signed_first_stage`，
不把比值包装成稳定精确的结论。

## 6. 模拟验证

`simulation` 用与真实资料完全隔离的四类 DGP 验证方法本身：

| DGP | 真值/目的 | 合格标准 |
| --- | --- | --- |
| `fuzzy` | ITT、FS、LATE 真值已知 | 偏差小，95% 区间覆盖率接近名义水平 |
| `no_first_stage` | 领取率不跳跃 | 弱一阶段闸门近乎必触发，ITT 误报率受控 |
| `manipulation` | 评分堆积且基线不连续 | 堆积或基线诊断高概率报警 |
| `heterogeneous` | 离散整数评分 + 批次异质效应 | 支撑识别判离散，随机化路径区间有限且为正 |

模拟只使用标准库，固定随机种子，覆盖率验证用解析聚类稳健区间以控制
运行时间；wild bootstrap 作为真实小样本分析的附加推断。

## 7. 证据边界与“扩围”问题

局部断点识别的人群是**阈值附近的合规企业（compliers）**，效应不能外推
到远离阈值的企业。因此即使三个跳跃都成立，也只能回答“阈值附近资格
规则带来的局部效应”，不能单独回答“把资格线扩大到更宽人群的整体效果”。
后者需要额外的外推假设或新的实验/准实验证据，报告中明确列为尚不能
回答的问题。
